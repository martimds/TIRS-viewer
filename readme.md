# TIRS-viewer

Data provided by USGS through INPE's [Brazil Data Cube STAC catalog](https://data.inpe.br/bdc/stac/v1/), using the `landsat-2` collection.

**PS:** Readings from February 9, 2023 (02/09) show striping. [See here.](https://www.usgs.gov/landsat-missions/landsat-9-oli-and-tirs-calibration-notices#2023-03)
